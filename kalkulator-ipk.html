Apa itu IPK dan IPS?

IPK (Indeks Prestasi Kumulatif) adalah rata-rata nilai akademik seorang mahasiswa selama menjalani seluruh masa studinya, dihitung dari semester pertama sampai semester terakhir. IPK menjadi salah satu tolok ukur utama prestasi akademik dan sering digunakan sebagai syarat kelulusan, beasiswa, maupun seleksi kerja.

Sedangkan IPS (Indeks Prestasi Semester) adalah rata-rata nilai yang diperoleh dalam satu semester tertentu. IPS menggambarkan performa kamu dalam satu periode kuliah saja.

Rumus Menghitung IPK

Rumus IPK sangat sederhana:

IPK = Σ (SKS mata kuliah × Bobot nilai) ÷ Σ SKS

Artinya, kalikan setiap SKS mata kuliah dengan bobot nilai yang kamu dapatkan, jumlahkan semuanya, lalu bagi dengan total SKS yang kamu ambil.

Contoh Perhitungan Langkah demi Langkah

Misalkan dalam satu semester kamu mengambil 3 mata kuliah:

  1. Mata Kuliah A — 3 SKS — nilai A (4)
  2. Mata Kuliah B — 2 SKS — nilai B (3)
  3. Mata Kuliah C — 3 SKS — nilai B+ (3.3)

Langkah 1: Hitung bobot masing-masing:

  • A: 3 × 4 = 12
  • B: 2 × 3 = 6
  • C: 3 × 3.3 = 9.9

Langkah 2: Jumlahkan bobot = 12 + 6 + 9.9 = 27.9

Langkah 3: Jumlahkan SKS = 3 + 2 + 3 = 8

Langkah 4: IPK = 27.9 ÷ 8 = 3.49

Skala Nilai yang Didukung

Skala 4.0 Sederhana:

  • A = 4
  • B = 3
  • C = 2
  • D = 1
  • E = 0

Skala Plus/Minus:

  • A = 4.0
  • A- = 3.7
  • B+ = 3.3
  • B = 3.0
  • B- = 2.7
  • C+ = 2.3
  • C = 2.0
  • D = 1.0
  • E = 0

Pertanyaan yang Sering Diajukan (FAQ)

Apakah kalkulator ini menyimpan data saya?

Tidak. Seluruh perhitungan dilakukan langsung di browser kamu. Tidak ada data yang dikirim ke server maupun disimpan di mana pun. Begitu kamu menutup halaman, data input akan hilang.

Apakah skala nilai di kalkulator ini sama dengan kampus saya?

Kalkulator ini menggunakan skala umum yang banyak dipakai di perguruan tinggi Indonesia. Namun, beberapa kampus memiliki skala nilai yang sedikit berbeda (misalnya nilai A = 4.0, AB = 3.5, atau ada nilai AB+/BC+). Selalu cek pedoman akademik kampusmu untuk kepastian.

Berapa IPK yang dianggap bagus?

Secara umum di Indonesia, IPK di atas 3.50 dianggap sangat baik, 3.00–3.49 baik, 2.50–2.99 cukup, dan di bawah 2.50 perlu perbaikan. Namun, standar ini bisa berbeda tergantung kampus dan program studi.

Apakah kalkulator ini bisa dipakai di HP?

Bisa. Website ini dirancang dengan pendekatan mobile-first, sehingga tampilannya otomatis menyesuaikan layar HP, tablet, maupun komputer.

Bagaimana jika saya salah memasukkan nilai?

Kamu bisa langsung menghapus baris mata kuliah dengan tombol hapus (🗑️) di sebelah kanan, atau tekan tombol Reset untuk mengosongkan seluruh isian.

⚠️ Peringatan: Hasil perhitungan di kalkulator ini hanya bersifat perkiraan. Skala nilai, pembulatan, dan kebijakan akademik bisa berbeda di setiap perguruan tinggi. Selalu gunakan hasil resmi dari akademik kampusmu sebagai acuan utama.
